# QuickTeX

A phone-first LaTeX maths notebook. Maths renders in place as you type, snippets expand as you write, and a key row
sits above the keyboard. It installs as an app and works fully offline.

**Open it:** https://unga-bunga-coder.github.io/QuickTeX/

Notes are saved on your device only. Use **Export all notes** in the menu to back them up.

## Install

- **iPhone:** open the link in Safari, tap Share, then Add to Home Screen.
- **Android:** open the link in Chrome, tap ⋮, then Add to Home screen (or Install app).

Open it once while online so it's saved for offline use.

## Develop

```sh
npm install
npm run build   # writes the site to dist/
npm test
python3 -m http.server -d dist
```

Every push to `main` builds, tests and deploys to GitHub Pages. See [CLAUDE.md](CLAUDE.md) for how the code is laid out.

### Inspiration

- **Gilles Castel**, [How I'm able to take notes in mathematics lectures using LaTeX and Vim](https://castel.dev/post/lecture-notes-1/).
  The snippet system (mk, dm, x1 → x_1, sr, //, ;a → α and friends) is adapted from his UltiSnips setup.
- **SeniorMars**, [dotfiles / latex_template](https://github.com/SeniorMars/dotfiles/tree/main/latex_template).
  The Vim + LaTeX note-taking workflow that started this project.
- **artisticat1**, [Obsidian LaTeX Suite](https://github.com/artisticat1/obsidian-latex-suite).
  The idea of a single pane where LaTeX renders in place as you type.
